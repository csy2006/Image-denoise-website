# PrismDen · 棱镜降噪

一个完全运行在浏览器中的图像降噪与色彩工具集。核心降噪算法为**双边滤波（Bilateral Filter）**，在 Web Worker 中本地执行，无需部署任何后端服务器。除降噪外，项目还包含创意滤镜、旅行票根（EXIF 识图）与主色调提取三个独立模块。

本项目为个人自学练习项目，所有算法与界面均由原生 HTML / CSS / JavaScript 实现，不依赖任何图像处理库或前端框架。

* * *

## 功能特性

| 模块  | 说明  |
| --- | --- |
| **图像降噪** | 基于双边滤波的保边平滑，去除传感器高斯噪声；支持空间域半径、值域标准差（σₛ / σᵣ）等参数调节；彩色与灰度两种模式 |
| **创意滤镜** | 胶片模拟、色调风格等预设滤镜，一键套用 |
| **旅行票根** | 解析照片 EXIF，自动识别拍摄地（GPS 逆地理编码）、拍摄日期与相机参数，生成带版式的票根卡片 |
| **调色盘提取** | 从图片中提取占比最高的主色调，生成「主色块 + 原图」上下等尺寸拼接的合成图，支持复制 HEX |

其他特性：中英文界面切换（i18n）、深浅色主题跟随系统、移动端与微信浏览器适配、处理进度实时反馈。

## 技术栈

* **前端**：原生 HTML / CSS / JavaScript（无框架）
* **降噪计算**：Web Worker（Blob URL 内联，兼容 `file://` 直接打开），Canvas 2D `getImageData` / `putImageData`
* **EXIF 解析**：`exif.js` + 自定义 GPS / 日期解析器

## 核心算法：双边滤波

双边滤波在普通高斯模糊的基础上引入**值域权重**，使滤波核同时考虑空间距离与像素值差异，从而在平滑噪声的同时保留边缘。

输出像素值计算公式：

    I'(p) = Σ_{q∈Ω} w_s(‖p−q‖) · w_r(‖I(p)−I(q)‖) · I(q)
            ─────────────────────────────────────────────
            Σ_{q∈Ω} w_s(‖p−q‖) · w_r(‖I(p)−I(q)‖)
    
    w_s(d) = exp( −d² / (2σₛ²) )        # 空间域高斯
    w_r(Δ) = exp( −Δ² / (2σᵣ²) )        # 值域高斯

其中 `σₛ` 控制空间邻域范围，`σᵣ` 控制对像素差异的容忍度：`σᵣ` 越小，边缘保持越强。

### 性能优化

双边滤波的朴素实现为每个像素做 O(r²) 次 `exp()` 计算，开销巨大。本项目采用以下优化：

1. **值域权重因式分解**：RGB 三通道的值域权重可独立计算，将三层 `exp()` 化简为三层查表加两次乘法。
2. **256 项查找表（LUT）**：将值域 `exp()` 预计算为长度 256 的 LUT，内层循环零 `exp()` 调用。
3. **倒数乘法替代除法**：权重归一化使用 `1/Σw` 一次倒数乘累加，避免每像素多次浮点除法。
4. **边界外提**：图像边界判断移出最内层循环。
5. **Web Worker 分块并行**：图像按块切分，逐块回传进度，避免主线程阻塞。
6. **零拷贝传输**：`postMessage` 使用 `Transferable` 直传 `ArrayBuffer`，不复制像素数据。

## 数据结构应用

项目以「手写数据结构并接入真实调用链」为练习目标，落地情况如下。

### 前端（实际调用）

* **最大堆 MaxHeap**（`palette.js`）：色彩量化后对所有颜色桶按频率建堆，取堆顶即为主色调。
* **哈希表 HashMap**：主色提取中将 RGB 各通道量化为 16 级（共 4096 桶）统计频次，键为量化后的颜色。
* **查找表 LUT**：值域高斯权重预计算，本质为定长数组的哈希映射。

### 后端参考实现（`server.cpp`，当前前端未调用）

后端同样以四种数据结构为练习对象，但部分仅完成类型定义、未接入实际调用链：

| 结构  | 状态  |
| --- | --- |
| `priority_queue<Tile>` | 已实例化，用于瓦片调度，但单线程串行下无负载均衡收益 |
| 手写 `HashMap`（`PairHash`） | 已定义，仅写入未读取 |
| `LinkedList` | 用于计数，实际滤波走扁平数组（平面化窗口更 cache 友好） |
| `TaskQueue` | 仅类型定义，全文未实例化 |

后端现状如实记录，便于后续将其改造为真正的多线程任务队列流水线。

## 本地运行

由于降噪在 Blob Web Worker 中执行，项目兼容 `file://` 协议，可直接双击 `frontend/index.html` 打开。若浏览器对本地文件的 Worker / 字体加载有限制，建议使用静态服务器：

    # 进入前端目录
    cd frontend
    
    # Python 静态服务器
    python -m http.server 8080
    # 浏览器访问 http://localhost:8080

或使用任意静态托管服务（如 GitHub Pages、Cloud Studio）部署 `frontend/` 目录。

## 已知限制与后续方向

* **噪声类型**：当前不对噪声类型做分类，统一按保边平滑处理，主要针对传感器高斯噪声。项目未实现椒盐噪声检测与中值滤波分支。
* **灰度模式缺陷**：Worker 约定的灰度模式标识与界面传入值不一致，导致灰度分支未生效、静默回退为彩色滤波（待修复）。
* **进度反馈**：进度条初始阶段为模拟值，真实进度自分块计算阶段开始。
* **后端未启用**：C++ 后端为参考实现，前端当前完全本地计算；后续可将大图降噪下沉至服务端多线程流水线。
* **算法对照实验**：可补充双边滤波与中值滤波、高斯模糊在合成噪声样本上的 PSNR / SSIM 对比，量化选型依据。
